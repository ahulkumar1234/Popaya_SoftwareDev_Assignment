# Full Stack Notes Application

A complete Full Stack Notes Application built as part of a Technical Assessment.

This project includes:

- Core Debugging Task
- Backend Notes CRUD API
- Frontend Notes UI
- MongoDB Database Integration
- Search Functionality
- Toast Notifications
- Responsive UI

---

# Tech Stack

## Frontend
- React.js
- Axios
- React Hot Toast
- Tailwind CSS
- Vite

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv
- cors
